# property-tracker-manager

A full-stack web application for managing maintenance logs and tasks in rental properties.

## 🚀 Tech Stack

- **Frontend:** Next.js 14 (App Router), Chakra UI
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas

## 🖥️ Features

- Track maintenance logs
- Assign logs to users
- Real-time updates via Socket.IO
- Mobile-responsive design
